# Fintech Design System

## Design Direction

The application should feel:

- Professional
- Trustworthy
- Modern
- Clean
- Premium
- Efficient

The interface should prioritize clarity
over visual decoration.

## Color

IMPORTANT:

Preserve the existing color palette.

Do not replace:

- Primary colors
- Secondary colors
- Background colors
- Text colors
- Semantic colors

New components must inherit the existing
theme/token system.

## Typography

Prioritize:

1. Financial values
2. Page titles
3. Section titles
4. Supporting information
5. Metadata

Large financial values should have strong
visual hierarchy.

## Layout

Prefer:

- Clear spacing
- Strong alignment
- Consistent grids
- High information density
- Responsive layouts

Avoid:

- Excessive empty space
- Excessive cards
- Unnecessary containers

## Components

Use existing:

- Radix UI
- Lucide React
- CVA
- clsx

Prefer reusable components.

## Animation

Use Motion for React.

Animation should communicate:

- State changes
- Hierarchy
- Interaction
- Navigation
- Feedback

Prefer:

- opacity
- transform
- scale
- layout

Avoid:

- excessive bouncing
- large movements
- animation everywhere

Respect prefers-reduced-motion.

## 21st.dev

21st.dev components may be used as
references or starting points.

Do not blindly copy them.

Adapt them to the existing:

- color palette
- typography
- spacing
- components
- accessibility
